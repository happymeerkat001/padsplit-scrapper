# PostgreSQL and VPS migration checklist

Scope: retain Firebase Authentication, preserve existing branch changes and outbound-action gates, and prepare an isolated, reviewable migration. No production cutover, provider sends, billing changes, or deployment promotion without authorization. Public Pages/history exposure remains an independent unresolved incident.

1. Inventory existing Firestore paths, browser readers/writers, backend jobs, authentication, snapshots, external services and macOS dependencies. Check actual target host and existing services before assigning ports or proxy paths. **Pass:** inventory reconciles with source and host access is explicitly recorded.
2. Build versioned PostgreSQL schema and privacy-preserving migration commands with stable source IDs, encryption for recoverable codes, idempotency and bounded transactions. **Pass:** migrations and repeated synthetic import run in an isolated database with negative-case checks.
3. Implement a Python API with Firebase token verification, trusted authorization, scoped access, validation, conflict protection and gated operations. **Pass:** authorization and failure-path tests use synthetic data; no credentials reach the browser.
4. Rehearse read-only export, encrypted backup, deterministic transform/import and verification; document write pause or validated catch-up and rollback. **Pass:** isolated restore and reconciliation checks succeed; never delete source data.
5. Prepare Vercel/VPS configuration with private PostgreSQL, worker gates, backups, CORS and reverse-proxy integration. **Pass:** local build and config checks; production remains untouched until explicitly approved.
6. Connect and verify browser workflows against the API, preserving authentication, draft state and accurate freshness. **Pass:** end-to-end behavior is tested for owner, restricted users and denials; unsupported paths remain labeled.
7. Update references and deliver a concrete status, required environment names, access gaps, and cutover/rollback sequence. **Pass:** documentation reflects measured behavior, not plans as completed work.
